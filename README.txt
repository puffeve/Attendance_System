ระบบนี้คือ ระบบบันทึกเวลาทำงานพนักงาน (Employee Attendance Management System)
ใช้สำหรับ HR และพนักงาน เพื่อจัดการ:
- เช็คชื่อเข้า–ออกงาน
- คำนวณเวลาทำงาน / OT / มาสาย
- ขอลา / อนุมัติลา
- ดูสรุปรายงาน
- จัดการพนักงาน
เป็นระบบ Full-stack Web Application

เทคโนโลยีที่ใช้
Backend
- Node.js
- Express.js
- REST API

Database
- MySQL relational database

Frontend
- HTML
- CSS
- JavaScript 

Chart
- Chart.js
